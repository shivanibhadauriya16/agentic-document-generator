# 🤖 Agentic Document Generator

> AI-powered agentic workflow for generating and reviewing professional documents.

## 📌 Overview

The Agentic Document Generator is an AI-powered document workflow developed during my Generative AI internship at Infotact Solutions.

The project uses multiple AI agents to support structured document creation and review.

The workflow includes:

**Writer Agent → Critic Agent → Revision**

The Writer Agent generates a structured document from provided inputs, while the Critic Agent reviews the generated content for structure, clarity, and completeness.
